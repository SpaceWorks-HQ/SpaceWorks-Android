# Generated native client

`api/openapi.json` remains the byte-identical owner snapshot. `scripts/contract.py` selects implemented operation paths and their unchanged transitive schemas. Runtime gateways call generated Retrofit interfaces and construct generated request bodies; immutable app screen projections are not serialized transport models.

The pinned OpenAPI Generator 7.26.0 runs in an isolated process. `scripts/native_templates.py` reads its actual resolved jar, checks its Maven identity and exact upstream template hashes, and writes two build-only overrides. These preserve the original map-parent inheritance flags while emitting one constructor, annotate binary responses `@Streaming`, and apply `@JvmSuppressWildcards` to generated Retrofit interfaces. Seven Python checks run before builds; unknown versions/templates fail for review. Generated Kotlin and extracted templates stay out of Git.

Bootstrap and URI-or-empty inline schema mappings use the generator's raw inline names: `TenantBootstrapMakerspace_map_url`, `SocialLogin_redirect_uri`, `ReauthenticationSocialStart_redirect_uri`, `WebsiteSection_url` and `WebsiteSection_website_url` are native `String`s (each wire value is a URI string or an empty string), and `TenantBootstrapMakerspace_opening_hours` / `TenantBootstrapMakerspace_opening_hours_oneOf_weekly` are lossless `JsonElement`. The opening-hours values are empty or structured JSON objects. These calendar values are retained and unused by capability projection. `NullEnum` (an `enum: [null]` schema used only as the null arm of report-chart `partition`) is mapped to lossless `JsonElement`, because the generator emits an empty, uncompilable enum for it. The mappings avoid unsupported inline union scalar serializers without changing the owner contract, authentication unions, or request/response wire fields. Capability tests decode real generated bootstrap responses and require the returned makerspace ID to match the requested scope.

Each authenticated generated call captures its makerspace header. The observing CallFactory seam retains the underlying OkHttp call only to cancel streamed bodies safely: cancellation invokes thread-safe `Call.cancel`, and the IO reader alone closes the response body. QR downloads validate SVG MIME and a 512 KiB limit; the native QR renderer rejects external resources, scripts, entities and unsupported SVG structures. JSON error parsing preserves code/detail precedence and readable nested field paths.

HTTP redirects, cookies, browser-only headers and implicit service/connection replays are blocked. Reviewed mutations use generated endpoints, explicit user retries and a retained idempotency key only where the contract publishes that header. SDK callbacks never establish a paid status or an authenticated authority.
